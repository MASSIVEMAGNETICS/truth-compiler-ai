# Verified synthetic sample

`sample-report/` is generated by scanning four locally created, rights-safe fixtures: a tagged WAV master, a byte-identical backup, a different WAV mix, and a deliberately corrupt MP3. The reports use `AUTHORIZED_SYNTHETIC_SAMPLE` instead of the temporary machine path.

Regenerate it from the repository root after installing the package:

```bash
python tools/generate_catalog_sample.py
```

`sample-verification.json` records the complete before/after SHA-256, size, and modification-time manifest. A true `source_files_unchanged` value is the empirical non-destructive check for that run.
