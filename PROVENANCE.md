# Provenance and authorization

This is an original Massive Magnetics implementation of a bounded dense neural-network organ. It is not a fork and contains no copied upstream source. If this package is derived from another repository, record that parent, commit SHA, license, and attribution here before merge.

The model is educational/research software. A successful XOR test is evidence of bounded learning behavior, not evidence of general intelligence or production authorization. `production_authorized` is intentionally hard-coded false in the Victor adapter. A human/operator policy layer must grant any later deployment capability.

Evidence chain: dataset identity -> training report -> independent finite/prediction checks -> verification receipt -> parent hash. Static evidence never grants authority. `truth_ai/heuristic_ranker.hpp` is deliberately downstream of evidence collection and upstream of human/deterministic review prioritization; it cannot manufacture evidence.
