# Catalog Recovery 0.1.0

This first production candidate inventories a local audio tree without changing source audio. It provides SHA-256 exact-duplicate groups, embedded metadata and technical properties, local search, SQLite resume state, CSV/JSON exports, corrupt-file reporting, and checksum receipts.

The desktop packages are unsigned. Windows SmartScreen or macOS Gatekeeper may therefore require the owner to review and explicitly allow the download. Verify the downloaded ZIP against `SHA256SUMS.txt` before opening it.

Version 0.1.0 does not delete, rename, move, retag, or repair source audio. It does not detect similar-sounding or transcoded copies, and it does not establish copyright or royalty ownership.
