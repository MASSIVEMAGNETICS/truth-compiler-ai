MASSIVE MAGNETICS CATALOG RECOVERY 0.1.0

Open Massive-Magnetics-Catalog-Recovery, choose one music folder, choose an
output folder outside that music folder, and select Start scan.

The application reads supported audio files and writes its database, logs,
CSV files, JSON catalog, issue list, exact-duplicate list, and signed-off scan
receipt only to the output folder. It never deletes, renames, moves, retags, or
writes to source audio files. Exact duplicates are evidence for review, not an
instruction to delete anything.

Supported formats: MP3, WAV/WAVE, FLAC, M4A/M4B/MP4, AAC, OGG/OGA/OPUS,
AIFF/AIF, ALAC, and WMA. Some malformed files can still be hashed and
listed even when their embedded metadata cannot be parsed.

Keep the output folder if a scan is interrupted. Selecting the same source
and output folders resumes the scan and reuses unchanged file results.
